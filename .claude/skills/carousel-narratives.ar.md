# أقواس سرد الكاروسيل

اختر قوساً واحداً قبل بناء الشرائح. القوس يحدد ترتيب الشرائح وإيقاعها.

## الكشف التدريجي
- **متى تستخدمه:** إعلانات فيها طبقات متعددة من الـ "آها"، أو مواضيع تكون فيها الرؤية الحقيقية مفاجئة.
- **الهيكل:** كل شريحة تضيف طبقة سياق واحدة، تبني نحو نتيجة ما كان القارئ ليتوقعها من الغلاف.
- **لماذا:** الخلاصة تصل بقوة أكبر عندما يكون القارئ ممهداً. المفاجأة مكتسبة، لا مُعطاة.

## مشكلة → حل
- **متى تستخدمه:** المحتوى التعليمي، التعليمات، "هذا ما يغلط فيه أغلب الناس."
- **الهيكل:** افتح بنقطة الألم. كل شريحة وسطى = خطوة واحدة نحو الحل. آخر شريحة = الصورة الكاملة.
- **لماذا:** يتعلق بالاحتكاك المألوف ويؤتي ثماره بالقيمة. محرك قوي للـ Save.

## خرافة مقابل الحقيقة
- **متى تستخدمه:** المواقف المضادة للتيار، المفاهيم الخاطئة في المجال، "الكل يعتقد X لكن الحقيقة Y."
- **الهيكل:** شرائح متناوبة: خرافة → حقيقة → خرافة → حقيقة. الإيقاع يخلق زخماً.
- **لماذا:** يولّد نقاشاً ومشاركة. كل خرافة hook، وكل حقيقة هي المكافأة.

## القائمة
- **متى تستخدمه:** النصائح، الأدوات، الانتصارات السريعة، "N أشياء لم تكن تعرفها عن X."
- **الهيكل:** الغلاف يعلن العدد. كل شريحة وسطى = عنصر واحد مستقل. آخر شريحة = ملخص أو CTA.
- **لماذا:** قابل للتصفح، قابل للمشاركة، سهل الحفظ. يعمل لأي موضوع.

## قبل / بعد
- **متى تستخدمه:** قصص التحول، عروض المنتجات، تحسينات العمليات.
- **الهيكل:** النصف الأول = عالم "قبل". النصف الثاني = "بعد". آخر شريحة = الفرق.
- **لماذا:** التناقض حشوي. القراء يشعرون بالفجوة قبل أن يفهموها فكرياً.

## خطوة بخطوة
- **متى تستخدمه:** التعليمات، كيفية الفعل، العمليات المتسلسلة.
- **الهيكل:** كل شريحة = خطوة واحدة، مرقمة. آخر شريحة = النتيجة أو المخرج.
- **لماذا:** واضح، قابل للتنفيذ، معدل Save مرتفع. القراء يعودون عند التطبيق.
