# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a content creation repository for Instagram content covering all formats: Reels, Reel Loops, carousel posts, and single image posts. Content is personalized to the creator's profile defined in `user.md` and the agent configuration in `.claude/agents/`.

Each file represents **one content piece** (a specific topic, format, and angle). Within each file, `idea v1`, `v2`, etc. are iterations toward a final version ready to post. A new content piece about the same project gets its own new file (e.g., `project-carousel.md`, `project-tutorial.md`).

## User Context

Before generating any content, read `user.md` in the project root for personal context about the author (location, background, life situation, preferences, and content limits). This ensures accuracy in geographic references, personal details, and tone.

## Multilingual Support

This template supports multiple languages. Each language has its own agent pipeline:

```
.claude/agents/
├── setup.md                                   ← orchestrator: runs full setup
├── user-setup.md                              ← English personal context setup
├── user-setup.pt-br.md                        ← Portuguese (Brazil) personal context setup
├── ig-creator-agent-template.md               ← English template
├── ig-setup.md                                ← English setup → generates ig-creator-agent.md
├── ig-creator-agent-template.pt-br.md         ← Portuguese (Brazil) template
├── ig-setup.pt-br.md                          ← Portuguese (Brazil) setup → generates ig-creator-agent.pt-br.md
├── ig-creator-agent.md                        ← generated (English)
└── ig-creator-agent.pt-br.md                  ← generated (Portuguese)
```

### Choosing a Language

To create content in a specific language:
- **English:** `claude --agent ig-creator` → uses `ig-creator-agent.md`
- **Portuguese:** `claude --agent ig-creator-pt-br` → uses `ig-creator-agent.pt-br.md`

### Setup Process

Run `/setup` once — it will ask for your language preference, then configure everything:
1. Ask language choice (English or Portuguese)
2. Run `/user-setup` → fills in `user.md` with your personal context
3. Run `/ig-setup` (English) or `/ig-setup-pt-br` (Portuguese) → generates your agent profile
4. Ready to create content with `claude --agent ig-creator`

The `user.md` file is shared across both languages. Your personal context (background, hobbies, professional info) is language-agnostic and used by both agents.

## Repository Structure

```
your-ig-content/
├── CLAUDE.md        ← project instructions
├── user.md          ← author's personal context
├── .claude/         ← agents and config
│   └── agents/
│       ├── setup.md                     ← run once to configure everything
│       ├── user-setup.md                ← run once to fill in user.md
│       ├── ig-setup.md                  ← run once to configure your English creator profile
│       ├── ig-setup.pt-br.md            ← run once to configure your Portuguese creator profile
│       ├── ig-creator-agent-template.md ← English template (never edit directly)
│       ├── ig-creator-agent-template.pt-br.md ← Portuguese template (never edit directly)
│       ├── ig-creator-agent.md          ← generated (English profile)
│       └── ig-creator-agent.pt-br.md    ← generated (Portuguese profile)
└── posts/           ← all content goes here
    ├── project-name.md
    ├── ai-tips.md
    └── ...
```

Each markdown file in `posts/` represents **one content piece** with multiple iterations toward a final version. Files are named descriptively to indicate the topic, project, format, and/or angle.

Content can be in any Instagram format:
- **Reel** — Video + caption
- **Reel Loop** — Short looping video + long caption
- **Carousel** — Multi-slide posts
- **Single Post** — Image + caption

**Example files:**
- `posts/project-name.md` — First content piece about a specific project
- `posts/project-name-carousel.md` — Second content piece about the same project, carousel format
- `posts/ai-explained.md` — Educational content about an AI concept
- `posts/tool-review.md` — Content reviewing or showcasing a tool

**Naming convention:** Use the topic/project as base, add descriptors if needed (format, angle, version). Examples: `project-v2.md`, `project-tutorial.md`, `topic-explained.md`, `meme-series.md`.

## Content Format

### File Structure

Every content file must start with this header:
```
# Content Ideas - [Project Name] [emoji]
**Session**: foo
```

The `Session` value is the identifier from the AI tool used to generate the content, used to retrace the conversation that originated the content.

- **If generated by Claude Code**: When **creating a new file in `/posts`**, **always pre-fill the `Sessao` field with the intended session name** (derived from the filename, e.g., `posts/prompt-anthropic-study.md` → `prompt-anthropic-study`), then immediately ask the user to run `/rename <nome>` to match.
- **If generated by another tool**: use the session or conversation ID from that tool.

### Idea Block Structure

Each content idea follows a consistent structure:
```
## idea vN: "Title" (Audience Focus)
### generated by: Agent - Model - Tool

**Format:** Reel Loop / Reel / Carousel / Post
**Visual:** Description of what to film or design
**On-screen text:** Timed on-screen text overlays
**Caption:** Full Instagram caption with hashtags
```

**`generated by` field structure:**
- **Agent** — name of the custom agent used (e.g., `ig-creator`)
- **Model** — specific AI model version (e.g., `Sonnet 4.6`, `Gemini Flash 2.5`) — **not the company name**
- **Tool** — application/interface used to run the agent (e.g., `Claude Code`, `opencode`)

**Examples:**
- `ig-creator - Sonnet 4.6 - Claude Code`
- `ig-creator - Gemini Flash 2.5 - opencode`
- `manual` (written without AI assistance)

### Content Lifecycle

Each content file progresses through iterations:
1. **idea v1, v2, v3...** — Multiple iterations of the same content piece. Each version is a refinement toward the final deliverable.
2. **Final Version** — Once an idea is approved and ready to post, it becomes the final version (no version number).
3. **New File** — When starting a new content piece (even on the same project), create a fresh `.md` file with its own iterations.

**Example workflow:**
- `project-name.md` contains `idea v1`, `idea v2`, `idea v3` → one is approved → becomes the final posted version
- Next content piece on the same project starts as `project-name-carousel.md` with its own `idea v1`, `v2`, etc.
